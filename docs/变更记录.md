# 变更记录

## 2026-11-09 搭建

- 研读 DeepSeek《Super-agent 设计探索》与原型、卡兹克 agent-autoloop、hezberg 与 hongyaok 的两个 Hermes 实现，确定"profile + 看板 + 少量脚本"路线。
- 四个角色的 SOUL.md、`superagent:sa-router` / `sa-worker` 技能、授权头模板。
- Router（planer）在飞书与命令行收窄到看板和记忆类工具，模型换为 claude-sonnet-5-5。
- 飞书白名单由空改为只允许本人，群策略由 open 改为 allowlist。
- 看门狗 cron `sa-watchdog`，每 10 分钟，no-agent，投递到飞书。
- sa-gate 插件（`/sa`、`派单` 零 token 建卡）。第一版只用 `post_gateway_admission` 钩子，飞书回"Unknown command"；原因是网关先处理斜杠命令，未注册的直接拒绝。改为 `ctx.register_command("sa", …)` 后端到端验证通过。

## 2026-11-10 调整

- 发现进 triage 的卡被内置拆分器整篇重写、授权头丢失。`kanban.auto_decompose` 改为 false，不指名的活默认交 planer。
- sa-gate 改为每次请求读配置；随后因单人自然语言用法用不上，整体禁用，代码移到 `optional/`。
- planer 的 SOUL 新增"拆分规则"：不必拆的不拆、2 到 6 张、能并行不加依赖、子卡自带目标做法验收标准与授权头、多卡时建汇总卡给自己收口。
- 看门狗：同批去重、6 小时重提、Kanban 已推送过的卡延后 6 小时、清空收尾（用户自改）；卡死检测改为按最近一次心跳或评论计时，30 分钟无活动点名；错误按命令做键；有新增只报新增。
- 文档：面向客户的《使用说明》、《问答备忘》、本文、《设计说明》、《运维与排错》。
- 角色可增删：角色清单只在 `superagent.config.json` 的 `workers` 里维护；安装时把清单渲染进 planer SOUL 的 ROSTER 块；没有专属 SOUL 的新角色用 `souls/_worker_template.md` 生成；planer 的 SOUL 改为"按描述匹配、没有合适角色先问、专门知识用按卡挂技能"。
- 新增万能工人 `worker`（默认模型，全工具），承接编码、研究、审查之外的一切执行任务；planer 规则改为"不属于三类的活派给 worker 并挂技能，同类活第三次出现时建议升格，建不建由人定"。曾考虑给 planer 一个"自建角色"工具，因会打开自我扩张的口子而搁置，设计留在问答备忘。
- 打包：集中配置 `superagent.config.json`（个人信息，不入库）与 `superagent.config.example.json`；`install.ps1` 升级为幂等的一键部署（建 profile、装 SOUL 技能脚本、写 kanban 配置、Router 收权与模型、建 cron、检查飞书白名单）；新增 `uninstall.ps1`、`.gitignore`、MIT 许可证。
